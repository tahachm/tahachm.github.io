At GreatFrontEnd, I designed and deployed a scalable, real-time **artifact search engine** combining vector (semantic) and lexical search.

The system scales to **over 110,000 data points** while keeping search latencies **under 50ms**, deployed on [Railway](https://railway.app/). Alongside this, I led development of a layout-generation pipeline using Gemini's multimodal models and OpenCV, drawing on published research in automated layout generation.

Stack: vector databases, semantic + lexical retrieval, LLM orchestration, OCR, OpenCV.
